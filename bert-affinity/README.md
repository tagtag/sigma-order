# MLM の Glauber 動力学におけるエントロピー生成 — パイロット

2026-11-09 / 田口善弘・Astra

## 目的

マスク言語モデル(MLM)の条件付き分布が整合的な同時分布を持たないことは
[arXiv:2605.16378](https://arxiv.org/html/2605.16378) が rectangle test で示している。
しかし同論文は「破れているか否か」を二値で判定するだけで、**どれだけ破れているかを
測っていない**。本パイロットは、その欠落を Schnakenberg のネットワーク理論で埋める。

単一サイト Glauber 動力学

    P(x -> y) = (1/L) * p_theta(y_k | x_{-k})        (x, y は site k のみ相違)

に対し、Kolmogorov のサイクルアフィニティ

    A_c = log [ 順回りの遷移確率の積 / 逆回りの遷移確率の積 ]

と、厳密なエントロピー生成率

    sigma = sum_{x != y} mu(x) P(x->y) log [ mu(x)P(x->y) / (mu(y)P(y->x)) ]

を計算する。`A_c = 0` が全サイクルで成り立つことと、整合的な定常分布に関する
詳細釣り合いが成り立つことは同値(Kolmogorov 判定条件)。

2サイト4状態サイクルの場合、アフィニティは結合の非対称性に簡約される:

    D_i(u) = log p_i(a'|u) - log p_i(a|u)      # site j = u のときの site i の対数オッズ
    D_j(v) = log p_j(b'|v) - log p_j(b|v)
    C_i = D_i(b') - D_i(b)                     # j の値が i の対数オッズを動かす量
    C_j = D_j(a') - D_j(a)                     # i の値が j の対数オッズを動かす量
    A   = C_j - C_i

整合的な同時分布 pi を持つモデルでは `C_i = C_j = log[pi(a',b')pi(a,b)/(pi(a,b')pi(a',b))]`
なので **A は恒等的に 0**。つまり A は「i から見た結合」と「j から見た結合」の
食い違いそのものである。

## 設計

`huggingface.co` が実行環境のプロキシで遮断されており BERT-base の重みが取得できな
かったため、**真の同時分布が既知の系**で厳密計算を行う方針に切り替えた。
パイロットとしてはこちらのほうが強い。地の真実が分かるので、
「推定誤差」と「目的関数由来の非整合」を分離できるからである。

- 系: L=6 サイト、アルファベット V=4 の**密結合ペアワイズ MRF**(全サイト対に結合、
  距離で減衰)。状態空間は 4^6 = 4096 で**全列挙可能**。
- したがって以下がすべて**厳密値**(推定器・モンテカルロ誤差なし):
  真の分布 pi とその条件付き分布、4096x4096 Glauber 遷移行列、その定常分布 mu
  (べき乗法、残差 < 1e-14)、エントロピー生成 sigma、全サイクルのアフィニティ。
- 比較する3者:
  - **TRUE**: 真の MRF の厳密な条件付き分布。詳細釣り合いが成立 → sigma = 0 のはず。
  - **AR**: 小型自己回帰 Transformer。**構成上**整合的な同時分布を定義するので、
    当てはまりの良し悪しに関わらず sigma = 0 のはず。これが本質的な対照群。
  - **MLM**: 小型マスク Transformer。マスクは**毎回ちょうど1トークン**
    (単一サイト Glauber と厳密に一致する、MLM にとって最も有利な条件)。
- 学習データ数 N を 1,000 / 10,000 / 100,000 と振り、有限データ誤差と
  目的関数由来の寄与を分離する。
- 両モデルとも d=96, 3層, 4ヘッド, 3000 ステップ, バッチ256, AdamW(lr 3e-3, cosine)。

真の条件付きエントロピーは 7.1524 nats(一様なら 8.3178)。

### 読み取り

1. **コードの検証**: TRUE と AR はすべて sigma ~ 1e-17..1e-19、すなわち倍精度の
   機械ゼロ。AR のアフィニティは `rms|A| = 0.0000`(厳密にゼロ)。理論通り。

2. **sigma は精度ではなく整合性を測る**。N=1,000 で AR の当てはまりは MLM より
   **悪い**(KL 0.926 対 0.575)にもかかわらず sigma = 0。逆に MLM は当てはまりが
   良くても sigma = 0.140。この分離が本手法の肝である。

3. **MLM の sigma はデータを増やしても頭打ちになる**: 0.140 → 0.0173 → 0.0144。
   データを10倍(1万→10万)にしても 17% しか減らない。アフィニティも
   rms 0.63 → 0.50 nats、max は 2.1 nats のまま残る。

4. **損失の直接比較は無効**(初版の誤りを訂正)。MLM の損失 1.1360 と AR の 1.1941 は
   下限が異なるので比べられない。MLM は $p(x_k|x_{-k})$ で両側5サイトを見るのに対し、
   AR は $p(x_k|x_{<k})$ で左側のみ(平均2.5サイト)であり、MLM の課題のほうが易しい。
   `floors.py` で真の下限を厳密計算すると:

   | | 下限 | 実測 | 超過 |
   |---|---|---|---|
   | AR | H(x)/L = 1.1921 | 1.1941 | **+0.0020** |
   | MLM | mean H(x_k&#124;x_{-k}) = 1.1185 | 1.1360 | **+0.0175** |

   自分の下限からの距離で測ると **MLM は AR の約9倍悪い**。初版の
   「トークン単位では MLM が勝ち、生成分布では負ける」という記述は誤りで、
   N=100,000 では超過損失・sigma・KL(mu||pi) の三者がすべて同じ向きに揃う
   (AR: +0.0020 / 3.3e-19 / 0.0067、MLM: +0.0175 / 0.0144 / 0.0401)。

5. **sigma の精度非依存性が出ているのは N=1,000 の行**。そこでは AR の当てはまりが
   MLM より**悪い**(KL 0.926 対 0.575)にもかかわらず sigma は厳密に 0、
   アフィニティも 0.0000。整合性と精度が独立であることを示すのはこの行である。

6. **未確認の観察**: MLM の超過損失 0.0175 nats と sigma = 0.0144 nats が同オーダー。
   「条件付き損失の超過分の大半が、いかなる同時分布からも生じ得ない非整合成分で
   説明される」という不等式が成り立つ可能性があるが、本実験では区別していない。
   超過損失を整合成分と非整合成分に分解して別々に測る必要がある。

## 解釈上の留保

- 無限データ・無限容量の極限では、MLM は真の条件付き分布を学習でき、それは整合的
  なので sigma → 0 になる。したがって**「MLM の目的関数が原理的に非整合」とは
  言えない**。本結果が示すのは、sigma が有限資源下での非整合性を測る量であり、
  実用的な学習スケールでは消えないということ。この「原理的には可逆だが計算資源の
  制約で不可逆」という構造は、[Arrows of Time for LLMs](https://arxiv.org/html/2401.17505v1)
  の計算論的不可逆性の議論と同じ形をしている。
- 頭打ちの原因が有限容量なのか有限データなのかは本実験では分離していない。
  モデル容量のスイープが次の一手。
- 実 BERT は未測定(環境の制約)。`cycle_affinity.py` が実 BERT 用のスクリプトで、
  `huggingface.co` に到達できる環境ならそのまま動く。

## 次の一手

1. 容量スイープ(d, 層数)で sigma の頭打ちの由来を分離。
2. マスク率を1トークンから複数トークンへ上げる(Glauber からの乖離が sigma をどう
   増やすか)。
3. 実 BERT / RoBERTa で `cycle_affinity.py` を回し、アフィニティ分布を
   サイト間距離の関数として出す。
4. Sagawa–Ueda 側: 文脈を「測定」とみなしたときの相互情報量 I を測り、
   `<e^{-sigma-I}> = 1` と `<sigma> >= -<I>` を数値検証する。
   L=6, V=4 なら厳密に確認できる。

A Non-Markovian Perspective*, PRX Intelligence (accepted, 2026), DOI: 10.1103/tv38-b23y,

## プロトコル(確認済み)

固定テキスト解析は、テキスト1本につき1つの量に帰着する。

    sigma_token = log P(順方向トークン列) - log P(トークン反転列)
    sigma_block = log P(順方向トークン列) - log P(ブロック反転列)

いずれも**同一のARモデル**で評価する(Crooks 的プロトコル反転であって、
ベイズ的遡及推定ではない)。repo には生の対数尤度 (`ll_fwd`, `ll_token_rev`,
`ll_block_rev`) が同梱されているので、**言語モデルを一切動かさずに統計層全体が
再計算できる**。`reproduce_sagawa_stats.py` がそれを行う。

重要な含意: **必要なのは「列の対数尤度を返す関数」ただ一つ**である。
評価器を差し替えても変わるのは3つの対数尤度列だけで、下流は不変。
任意順(マスク拡散)への拡張は、この1関数の差し替えに帰着する。

## 再現結果

全14コーパス、計1,820テキスト。

**(1) σ の定義**: `sigma = ll_fwd - ll_rev` が全コーパスで最大偏差 ~1e-13
(float64 の丸め)。定義は確定。

**(2) 統計量**: $U$ と rank-biserial $r$ が**全行で同梱値と一致**。
Table III(Qwen3-4B-Base)の10行すべてが漸近+連続補正の値と一致
(例: qwen3/Opus46 block = 3.5845e-12 ↔ 論文 3.585e-12)。
Table II と本文の $p = 4.5\times10^{-6}$ は exact 検定の値(4.4731e-06)。

**(3) 検定法の記述不一致(軽微)**: 論文の方法記述は3箇所で
"two-sided asymptotic Mann-Whitney U test ... with continuity correction"
とあるが、GPT-2 側の `mann_whitney_test.py` 100行目は `method="exact"` を呼ぶ。
Table II は exact、Table III は漸近。**結論は変わらない**: 境界上の行
(qwen3/GPT56 block)は exact 4.5082e-02、漸近 4.5246e-02 で**いずれも 0.05 未満**、
よって「5生成器すべてで有意」は両方式で成立する。

**(4) 評価器の規模が効く**(論文の主張の確認)。ブロック水準で、
GPT-2(117M)は5コーパス中2つで有意差を出せない
(gpt2/GPT54: r=0.0934, p=0.25 / gpt2/GPT56: r=0.0936, p=0.25)。
Qwen3-4B-Base では5/5で有意。**拡張時の評価器は4B級以上が要る。**

**(5) トークン水準は符号が反転する**。$r$ は gpt2/GPT56 の −0.4626 から
qwen3/Gemini31 の +0.1938 まで分布し、新しめのコーパスでは**負**
(因果的テキストのほうが σ_token が小さい)。論文が「統語的な人工物」と
呼ぶ理由がデータから確認できる。**信号はブロック水準にある。**

なお qwen3/Opus46 の非因果テキストはブロック水準の中央値が **−0.0275**、
すなわちエントロピー生成が負(反転列のほうが尤度が高い)。

## 拡張の差分

上記より、任意順生成への拡張で書き換えるべきは1箇所だけである。

| 部分 | AR(現状) | マスク拡散(拡張) |
|---|---|---|
| `ll_fwd` 等 | 因果LMの対数尤度 | **アンマスク順序を指定した**対数尤度 |
| 反転の定義 | トークン順/ブロック順 | 同左(不変) |
| 統計層 | Mann-Whitney U + r | 同左(不変) |

順序介入は `ll_*` を順序 π ごとに計算し、$\sigma$ の因果/非因果分離が
順序不変かを見る。不変なら矢は内容にあり、依存するなら
「談話構造の慣習」の寄与が分離できたことになる —— 論文第VIII節が
「極めて非自明な未解決問題」として挙げた三寄与の切り分けにあたる。
